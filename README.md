# Clerk auth demo

1. Install dependencies.

```bash
npm install
```

2. Copy `.env.example` to `.env` and fill in your Clerk keys.

3. Run the backend.

```bash
npm run dev:server
```

4. Run the frontend in a second terminal.

```bash
npm run dev:web
```

5. Open `http://localhost:5173`, sign in with Clerk, then click `Fetch /me`.
